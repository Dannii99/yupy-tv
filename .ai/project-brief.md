# Project Brief

## Contexto
Frontend Angular (latest) con:
- Arquitectura: Standalone components + Standalone routes
- Estado: Signals (local/UI) + RxJS (streams/async/HTTP cuando aplique)
- UI: NG-ZORRO (Ant Design Angular)
- Estilos: Tailwind CSS (layout/spacing) + SCSS (overrides y estilos específicos)
- Formato: Prettier

## Objetivo
Construir features rápidas y robustas con calidad Senior:
- Tipado estricto
- UI consistente
- Performance
- DX (developer experience)

## Restricciones
- No introducir dependencias nuevas sin justificar.
- No romper contratos existentes.
- Evitar lógica compleja en templates.
- Mantener consistencia con `.ai/*`.
